# 未訪問ワールドのスナップショットと地図の境界

複製人間がいないワールドのスナップショットで、警告文の組立時に空の一覧へ最大値計算を行う問題を修正した。取得済みの対象ワールドの人数をそのまま使用し、全コロニーの人数で補完しない。住民がいない場合の最大ストレスはnullとして返し、要約では該当者がいないことを示す。監視閾値もnullを0として評価しない。

地図の埋蔵マーカー補足は、共通の可視性・ワールド境界を確認してから本体の可視化情報を読む。他ワールドや未観測セルのマーカーを混入させない。ワールドの訪問状態や地形を変更する処理は追加していない。

変更した要約・警告の3文言は、POテンプレートと3言語のPO、既存の3言語実行用JSONへ配置した。既存の言語解決方法は維持する。

## 検証

公開作業ツリーで実装を連結したホスト試験201条件、既存Tools回帰、翻訳3キーの照合、ゲーム同梱DLLによる参照Compileが成功した。参照Compileの警告・エラーは0。開発側では8種の不具合再導入を試験が検出した。依存関係のオンライン監査は当該実行で省略した。

開発識別子での実機62条件では、住民のいるワールド・いないワールド・全体の区別、nullと既知の0に対する監視、表示抑制、地図の境界と復帰、訪問状態・停止状態の保持を確認した。公開識別子を配備した変更後の実機受入は未実施。個別セーブや生の応答・ログ・設定は公開内容に含めない。

## 対象外

住民がいない場所の設備不足警告、個別の未取得amount値、埋蔵マーカー集計の未観測と0の区別は別項目として残る。既存index応答のテキスト上限も変更していない。
