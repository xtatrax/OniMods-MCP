# 操作ファイルのヘルプ文のローカライズ

通常の操作ファイルを生成する `ReadOperationMarkdown` のモード・編集ヒント・構文案内の3文を、`operation_files.mode_hint`・`edit_tip`・`syntax_hint` へ分離する。`/active/ops/tools.md` が委譲する別の案内本文や、その他の見出し・例文は今回の対象に含めない。操作ファイルを読むだけでコマンドを実行する動作は追加しない。

英語は次の従来3文をそのまま保持し、日本語と既存の簡体字中国語ランタイムカタログへ訳文を追加する。`## Edit Commands`、SEARCH/REPLACE、SEARCH、`call tool=<tool_name> key=value ...`、`tool=` は処理用の構文として維持する。実行用見出し・Tool JSON・コメント付きコマンド例・DSL自体は変更しない。

```text
- mode: edit lines under `## Edit Commands`, then submit SEARCH/REPLACE.
- edit tip: use an empty SEARCH block to run fresh commands, or copy the current snippet exactly.
- syntax: `call tool=<tool_name> key=value ...`; in typed files, `tool=` is optional.
```

既存4キーの値を保持し、追加3キーと合わせて7キーを扱う。POテンプレート・`en-us.po`・`ja-jp.po`・暫定の `zh-hant.po` に追加3項目を同期し、既存の簡体字中国語訳は各項目の別正本コメントと `zh-Hans` ランタイムカタログで保持する。暫定Hant訳を既存Hans訳として流用しない。

検証スクリプトは、各リポジトリ内でPO全体のコンテキスト集合・原文・数値プレースホルダーを照合する従来のガードを保持する。その上で、操作ファイルが使用するキー・各ランタイムカタログ・該当POコンテキストを固定の7項目へ厳密に揃え、訳文の空欄と追加3文の予約構文・単一行形式を検査する。開発版と公開版のPO全体が互いに同一であることを要求するものではない。

専用検査で7キー・PO4・ランタイム3の対応を確認し、既存OperationResults回帰も通過した。追加した既存メソッド内の検査は、3言語の実生成本文・英語旧3文・数値プレースホルダー・予約見出しとDSL・fixtureのTool JSON・子実行0を照合する。旧Reader全文への差替えはコンパイル後、日本語の案内文が選択されない意味検査で失敗した。初回の新テストは既存の末尾2例を期待値へ含めておらず、その2行を加えて全文一致を保った。製品の例文は変更していない。

開発版と公開版それぞれ自身の本体参照0警告0エラーと配備DLLの停止実機で、MCP言語を通常設定からen→ja→既存Hans→autoへ変更し、3言語×3文書の計9取得と9反復を確認した。追加3文・既存の可変説明だけを正規化し、残りの本文・予約構文・例文と機械用JSON項目の保持を照合した。各言語保存後に旧セッションの拒否を確認し、次段階は新セッションで読んだ。全設定JSONを復帰させ、元セーブ・停止時計・報告視点・固有設定先と所有パッチ／重複なしを保持し、保存や進行を要求せず通常終了した。元の導入物・設定・画像と保護セーブ・他MOD／DLC・共有データと未起動へ復帰した。公開版固有の設定先と所有パッチID・重複なしも独立に照合した。切替時の単一MOD不一致は、観測した対象を通常OK経路へ一度だけ委譲し、停止を保持した。

これは文書本文と設定復帰の限定受入であり、ブラウザー／PLibの描画・ゲーム言語変更・native子コマンドの実行試験や実機内部の非実行計測ではない。

この3文の受入を、全ヘルプ・全表示文のローカライズやローカライズ移行全体の完了として扱わない。ホストでの検査と本体上の限定動作確認は、それぞれの根拠として区別する。
