# 収納フィルターの応答再読取

現行のset_filterは、本体のTreeFilterable.UpdateFilters後にGetTagsを読み直してから応答を返している。過去の変更前タグ返却を防ぐ既存修正に対し、回帰試験を追加した。追加の本番コード修正はない。

acceptedTagsは更新後の本体状態、massStoredKgは応答作成時点の本体Storage値である。後からの排出・運搬・搬入の完了保証ではない。必要な時点で独立したstorage/detailを読み直す。対象選択、対応モード、複数Storageの扱いは変更しない。

公開作業ツリーで、実StorageTools・StorageTargetResolver・JSON設定を連結したホスト120条件を実行。開発側では、更新後タグ再読取の削除と要求値の単純echoの2変異を検出した。ネイティブコールバックは境界用の代替型であり、ゲーム内の受入条件・排出時刻の証明ではない。MCP確認制約と実際のアクティブワールド解決はこのホスト試験に含まれない。

開発識別子の実機61条件では、replace/add/removeの応答と独立detail、収納物の排出・床の現物・短時間進行後の状態を確認した。試験後は保存分岐から元の収納・時刻・原本・設定を復元した。公開識別子での変更後実機受入は未実施。個別セーブ、実ID、座標、生ログ、画像、設定は含めない。

本項目は試験・文書のみの変更である。本体コードは前項のゲームDLL参照Compile成功時から不変で、新規の参照ビルドを実行したとは扱わない。
