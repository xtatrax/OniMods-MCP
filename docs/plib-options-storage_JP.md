# PLib設定と正規保存先

PLibのゲーム内設定と、サーバーが使用する設定を同じ内容へ結び付ける限定的な保存アダプターです。
各版の既存の設定ファイル名と保存先の解決規則を維持します。別版の設定のコピーや自動移行は行いません。

## 保存先と所有型

`[ConfigFile(filename, true)]` の第2引数は整形出力の指定で、共有保存先の指定ではありません。
PLibの標準保存先と、永続データ領域の既存ファイルを優先するOniMcpの正規保存先が異なると、表示設定とサーバー設定が分かれ得ます。
標準の保存後通知でMOD側が再保存すると、別々のファイルへの書込にもなり得ます。

アダプターは、設定を登録した所有側のPLibにある読取・書込処理を対象にします。
読取は厳密に同じ `OniMcpOptions` 型、書込はその厳密な実体型だけを扱います。
他MOD・派生型や別のPLibコピーの保存先を一括変更しません。
対象メソッドと両方のフックを確認できなければ、ゲーム内設定を登録せず、安全でない標準保存へ黙って戻りません。
正規保存先を新設・変更したり、トークンの二次保管先を作ったりする修正ではありません。

## 表示・編集・保存

アダプターの読取では、初期化済みの現在設定から切り離したコピーを渡します。
`Current` の遅延読込、再読込、既定設定の構築や設定ファイルの書込を使って不足を埋めません。
未初期化や想定外の実体型は拒否します。現在の文字列・真偽値・整数を対象とするコピーであり、将来の任意の可変オブジェクトまで安全に複製する保証ではありません。

ダイアログ内の変更は切り離した設定へ反映されます。
通常のCancelは保存と保存後通知を行わず、再度開くと現在設定の新しいコピーを使います。
OKは既存の検証・正規化・原子的置換を行う `Save` を使い、PLibの別ファイルへの書込を省きます。
保存後の `OnOptionsChanged` は再保存せず、サーバー再起動の通知だけを行います。
アダプターの保存失敗は上位へ伝播し、保存後通知へ進みません。専用のエラー画面を追加した変更ではありません。
保存の成功、新しい待受先・認証による接続、通常再起動後の引継ぎは、それぞれ照合が必要です。

トークンは従来のマスク表示を使います。設定オブジェクトやウィジェット内部を汎用的にダンプする契約ではありません。

## 今回の検証入口

全項目試験には、所有側のPLibが公開する `POptions.ShowDialog(Type, Action<object>)` を、正確な所有設定型とnullのコールバックで呼ぶ固定経路を用います。
本体の通常の `OptionsDialog` と読取・書込処理を使い、編集・Cancel・OKは実際のウィジェットのイベントへ委譲します。
設定モデルへの直接代入、専用の非公開ダイアログ構築、追加の終了コールバック挿入は行いません。
この検証入口は私用の試験補助であり、製品へ新しい操作APIを追加するものではありません。

MOD管理画面の起動には、本体が登録状況に応じてMODを整理する処理が含まれます。今回の全項目試験では、この管理処理を経由せず所有側の公開factoryを使います。
途中のガード停止は、どのMODが購読対象外だったかや、実際に整理・無効化されたことを確定する証拠ではありません。
MOD管理ページの設定ボタン、登録整理や管理画面終了時の保存は、今回の受入対象ではありません。
公開factoryによる設定画面の試験を、そのボタン経路の試験成功とは扱いません。

## 検証状態と限界

実ソースを接続したホスト回帰と本体参照ビルドの確認はありますが、ネイティブのフックや画面を実行した証拠とは分けます。
開発版の全11項目と、公開版の全10項目を、それぞれのID・ソース・DLL・専用設定ファイルで確認しました。通常ダイアログ上の表示・ウィジェット編集、Cancel前後の設定バイト保持、再表示、OK後の保存、新しい待受先・認証による接続、通常再起動後の引継ぎが対象です。各版の画面で全項目とトークンのマスクを照合しました。
正規保存先と異なる値の旧保存先を用意し、正規設定が表示され、Cancelではどちらも変更されず、OKでは正規保存先だけが更新されることを確認しました。旧待受先と認証なし・旧トークンでは接続できず、新しい認証で接続できることも別に確認しています。
各版の試験後、元の導入物・設定・他MOD・保存データ・既存画像と、開始時の未起動状態への復帰を照合しました。本体が通常起動・終了で更新するセッション値以外は保持し、preferencesの直接書戻しは行っていません。
試験補助が安全検査で停止した試行や、その後の復旧は、設定保存の合格に数えません。
Web画面や非日本語ゲームでのauto追従は、この保存経路の受入とは別です。

物理的なキー入力やポインターの命中、任意の他MODによる変更、全ての不正入力・並行操作を保証しません。
設定試験はコロニーのロード・通常セーブ・ゲーム進行を必要とせず、復旧時の通常ロード等とは区別します。
[保存MODラベルの契約](saved-mod-footprint_JP.md)は別の受入範囲です。
