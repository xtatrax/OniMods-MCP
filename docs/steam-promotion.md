# Steam publishing in the public fork

Steam write operations are disabled. No owner account or default Workshop item is configured. The wrapper scripts refuse execution; the publisher retains its write-mode guard. The OniMcp CLI publication path also refuses.

Historical upstream item IDs in offline compatibility fixtures identify public upstream artifacts; they are not publication authorization. Test owner IDs are synthetic. Read-only checks require explicitly configured targets. Any future publishing implementation needs an independently owned item, reviewed ownership checks, and explicit authorization.
