# main からの変更点（公開フォーク）

この文書は、公開フォークで追加・変更した機能と、利用時に注意する互換性をまとめたものです。個人の環境設定、セーブ名、実機の生ログは含みません。

## 比較対象と読み方

| 対象 | 固定リビジョン |
| --- | --- |
| 比較元のローカル `main` | `60d7a5b7e4246e59b4fe2acf6c26596526d08ad0` |
| 公開スナップショット | `1f03cfac19819907108befb9658a59d78d0ee3af` |
| 差分を確認した日 | 2026-10-12 |

比較元は作成時点のローカル `main` であり、リモートの最新状態を示すものではありません。この2つの固定リビジョンでは **457ファイル、17,660行追加、6,145行削除**です。本書と案内リンクの追加はこの集計に含みません。説明文・コメントの日本語化も含むため、行数を機能追加の規模と読み替えないでください。

`fork_public` は開発履歴を引き継がない独立したルートコミットから始まります。比較には共通祖先を必要としない、次のツリー差分を使用します。`main...fork_public` のような3点比較やコミット一覧を、機能差分の根拠にしません。

```sh
git diff --stat 60d7a5b7e4246e59b4fe2acf6c26596526d08ad0 1f03cfac19819907108befb9658a59d78d0ee3af
git diff 60d7a5b7e4246e59b4fe2acf6c26596526d08ad0 1f03cfac19819907108befb9658a59d78d0ee3af -- mods/OniMcp
```

比較元のコミットが手元にある場合に実行できます。公開ブランチだけの取得では、比較元の履歴は含まれません。

## 日本語化と言語切替

- Rust CLI `onim` のヘルプ・エラー・案内、MCPの多数の説明文、ビルド設定の説明を日本語化しました。README、スキル、開発ガイド、各MODの説明には `_JP.md` を追加しています。
- MCP独自の表示文に `auto` / `en` / `ja` / `zh-Hans` の選択を追加しました。Web設定、公開ツール・引数説明、共通エラー、全体マップの案内などにカタログを使用します。
- ゲーム由来の名称とMCPの案内文を分離しました。ゲームの設備名・個体名などはゲーム側の言語を維持します。ツール名、JSONキー、Prefab ID、URI、enum値、地図記号は翻訳しません。
- ツールの分類・操作種別・危険度などのメタデータ処理を共通化し、翻訳用の説明取得を登録情報と分離しました。

全応答の翻訳完了を意味しません。個別操作の結果文や仮想Markdownには未移行部分があります。説明をキャッシュするMCPクライアントでは、言語変更後に再接続が必要です。[言語切替の契約](mcp-localization_JP.md)を参照してください。

- 既知のテキスト部品に加え、変換・レシピ・相変化などの専用パネルを構造化します。
- 長文のページ取得と内容変更の検出を追加し、打切りと取得完了を区別します。

## 通常操作とデバッグ操作の区別

| 操作 | 変更内容 |
| --- | --- |
| 設備の有効／無効 | 通常の `set_enabled` を直接代入から `BuildingEnabledButton.OnMenuToggle` による作業予約・取消へ変更。現在値・要求値・待機状態を分離し、InstantBuild時やAPI不一致時は拒否 |
| デュプ不要のスイッチ | `set_toggle` はゲーム本来の `IPlayerControlledToggle` 経路を使用。停止中の要求を維持し、シミュレーション再開時に反映 |
| デバッグ用直接変更 | `game_control domain=sandbox kind=entity action=set_building_enabled_debug` へ隔離。確認・sandbox/force検証、通常予約との競合拒否を適用 |
| 座標ラッパー | 内側の `dryRun=true` を外側の実行指定で上書きするなど、`dryRun` / `confirm` の矛盾を実行前に拒否 |
| 片付け指示 | 生存する複製人間を対象から除外し、除外理由・件数を返す |
| 収納フィルター | 変更直後の応答を古い検索時点のコピーから、更新後のタグの再取得へ修正 |
| 製造ポッド | 受取または全拒否で決着するようAGENTへ案内する設定と、通常の全拒否処理を追加。既定OFFでは方針メッセージを出さない |

[設備切替](building-toggle-audit-20261012.md)、[収納応答](storage-filter-response_JP.md)、[製造ポッド方針](printing-pod-selection-policy.md)に詳細を記載しています。製造ポッド方針はMODによる自動受取・自動停止ではありません。農業などmainに既にある操作も多く、説明の翻訳だけを新機能として数えていません。

- 開発過程で追加された個人の実機ログ・画像・セーブ情報は、公開スナップショットへの取り込み対象から除外しています。mainに存在しなかったものまで「mainから削除」とは扱いません。
- CIのpush対象に `fork_public` を追加しました。ライセンス、著作権表示、上流・移植元の出典は保持しています。
- CycleTrimとOniModTemplateは、今回の比較では主に日本語文書・説明文の変更です。CycleTrim本体の最適化アルゴリズムを新規追加した差分ではありません。

## 追補: 建材の数量診断

単一素材の建設必要量をネイティブ BuildingDef.Mass から取得するよう修正。配置のvalidとは別に、materialSelectionのrequiredKg・selectedAvailableKg・shortageKg・satisfied・quantityStatusで資材の充足性を返す。正の在庫不足でも設計図予約を一律拒否する変更ではない。在庫ゼロの拒否は維持する。

必要量／在庫未取得はnull・unknownとして返す。複数素材の総量を一つの素材在庫と比較しない。複数素材スロット、予約量、到達／運搬可能量は引き続き未評価。quantityScope・inventoryScopeを参照する。

不足、在庫ゼロ、境界、余剰、未取得／非有限値、複数素材、free-build例外のホスト回帰を公開作業ツリーで確認。開発版では参照ビルドと実機予行を確認したが、公開版固有IDでの実機確認は未実施。個別のセーブ名・座標・実機ログは公開差分に含まない。


## 追補: ブリッジ端点と対象レイヤー

建設予約・完成設備のブリッジをネイティブ定義と回転に従って読み、電力・液体・気体・輸送・自動化それぞれの欄だけに表示する。欠測は中央座標で代用せずunavailableとし、予定／完成と接続未評価を区別する。詳細は[ブリッジ端点](bridge-ports_JP.md)。

公開作業ツリーで端点取得のホスト85チェックを確認。開発版の参照ビルド・実機読取は成功したが、公開IDでの実機検証や実流量の確認を意味しない。個別のセーブ情報・実機ログは含めない。
