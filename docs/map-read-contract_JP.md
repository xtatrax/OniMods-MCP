# テキスト地図の読取・編集契約

## 読取範囲と表示

`world_editor` のテキスト地図は、要求した矩形とビューを使う。`zoom` の既定は `[default]` の1ビュー。カメラ・オーバーレイを変更するのは明示した `syncView=true` のときだけで、過去の読取によるカメラ範囲キャッシュは使わない。

- 明示する座標は整数の `x1,y1,x2,y2` 一式、または対応する `xMin,yMin,xMax,yMax` 一式。逆順・範囲外・欠損・不正型はエラーとし、別の範囲へ丸めない。
- `maxCells` は整数1～2500、既定900。viewport、設備レイヤー、矩形zoomと編集用読取に適用する。広いテキストlayerは座標を指定して必要部分に絞る。ブラウザーの全体マップやHTML層表示のサイズ制限とは別。
- セルは現在ワールドの可視範囲だけを読み、未探索・別ワールド・欠測を `?` で示す。空セルや真空と解釈しない。
- 既存の3桁Xヘッダーに合わせ、Xが1000以上のテキスト矩形は折返し表示せず拒否する。ブラウザー全体マップとは別の制限。
- 未対応ビューにdefaultビューを代用しない。`compact=true` は繰り返しの詳細・操作案内を省き、必要ならセル詳細または `format=edit` で再取得する。
- 隣り合う別設備は同じPrefabでも別個体として表示する。`@(x,y)` は注記したセルの座標であり、必ずしも建設アンカーではない。

## 接続と建材

電線・配管などは完成設備のネイティブ物理接続を読み、隣接していることや同一回路IDだけから接続線を推定しない。建設予定の接続方向は `plannedDirs` 等に分離する。接続値の欠測は `?`。完成・接続と実流量は別で、地図読取だけでは実流量を検証しない。

建設予定の建材は `Constructable.SelectedElementsTags` に従い、Prefabの初期元素で代用しない。複数素材は読取で列挙できるが、現行の単一素材地図編集では変更対象の複数素材トークンを実行前に拒否する。素材ごとのスロット指定対応を意味しない。

## 編集と打切り

設備は完全Prefab ID・完全表示名を優先し、曖昧な記号や名前を勝手に確定しない。優先度は1～9の整数だけ。SEARCH/REPLACEのY行集合とXヘッダーを検証し、不正な座標・対象・素材形式・優先度は指示の実行前に拒否する。

SEARCHの `?` と `*` はリテラル一致。1トークンのワイルドカードは `.*`、正規表現は `/regex/` または `~regex`。取得された `?` を空セルとして編集しない。既存のsandbox確認、通常工事、接続・切断の実行経路は維持する。

バッチの子結果を短縮した場合は `truncated=true` と元の `totalChars` を返す。省略された本文が必要なときは対象を直接読み直す。

## 検証の境界

ホスト試験は実ソースを参照し、境界・入力型・ビュー・カメラ同期の既定・計画と物理接続の分離・トークン拒否を確認する。本体参照ビルドと、実機での描画・接続状態・カメラ不変・無効編集の無変更確認は別の検証として扱う。
