# 任意の信号端点と配線不足案内

セルの Decision Hints は、本体 LogicPorts.Port.requiresConnection を参照し、任意の未接続端点を不足一覧に混ぜない。
このフラグは本体の配線不足アイコンの対象指定であり、設備の稼働条件や停止原因そのものではない。

| 観測 | 案内 |
| --- | --- |
| 接続済み | 要否によらず接続済み |
| 未接続・本体の不足警告対象 | 不足案内を保持 |
| 未接続・対象外の信号端点 | 任意の未接続として中立表示 |
| 本体定義と端点を対応できない | 要否未取得として表示 |

信号橋は回転後の実セルを両方の本体ポート配列へ対応させる。同じIDや、入出力へ正規化した表示上の役割だけで要否を決めない。
電力・配管・コンベアの従来案内、接続操作、ゲーム状態は変更しない。

4文言の原文・翻訳を Localization/po/ に保持し、現在の実行用 JSON カタログと照合する。
POローダーや言語選択肢の追加ではない。暫定の zh-Hant と既存 zh-Hans の文言は別に保持する。

実装を直接使うホスト73条件、誤判定を戻した変異2種の検出、PO/JSON検査、ゲームDLL参照コンパイルで検証する。
同じ実装の開発識別子では、任意入力・任意出力・本体警告対象・接続済み・回転橋・停止保持の実機33条件を確認した。
公開識別子での本変更後の実機受入とは区別し、個別のセーブ・座標・生ログは含めない。
