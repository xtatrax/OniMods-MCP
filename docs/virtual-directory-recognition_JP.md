# 掲載済み仮想ディレクトリの認識

対象は `/active/objects/` と `/active/buildings/instances/` の2パスに限定する。どちらも親の一覧が `dir` として掲載し、`ListEntries` に子の列挙処理がある一方、`IsDirectory` の明示一覧から漏れていた。`ls` と `cd` は同判定で拒否され、ブラウザーもファイル用の分岐を選んでいた。既存ファイルの直接読取とは別の入口不一致である。

修正は同じ明示一覧への2件追加のみ。子ファイル、名称、説明、取得対象、ファイル読取、編集、保存先、他のディレクトリ判定は変更しない。既存の `objects/` と `details.oni` の説明は、既存POとランタイムカタログを参照したまま保持する。パスとIDは翻訳対象ではなく、新規のランタイム表示文は追加しない。

ホスト回帰は既存 `OniMcp.OperationResults.Tests` へ追加し、実際の `WorldEditorListing.cs` と `WorldEditorBrowser.cs` 全文をリンクする。既存の実コマンド分岐と正規化を通して、親一覧から2パスへの `ls`・`cd`・ブラウザーの往復、建物一覧の空／非空、既存active直下ディレクトリ、現在のmapとopsの全掲載項目、存在しないパス・類似接頭辞・ファイルパスの拒否と失敗時cwd保持を検査する。ブラウザー専用mapリンクはMCPディレクトリに昇格しない。ネイティブの建物一覧と名前・ファイル名は入力境界とし、実機の列挙条件や命名規則を再実装しない。

`WorldEditorListingSource` で修正前の全文を指定した負対照は、コンパイル成功後に掲載ディレクトリへの `cd`／`ls` の実挙動で失敗する必要がある。文字列検索だけを回帰の合格条件にしない。ホスト側のファイル読取は既存snapshot境界のため、詳細内容の取得を実機受入済みとはしない。

実機では各版自身のDLLと識別子を確認した停止点で、親一覧→2ディレクトリの一覧→実際の子詳細読取を照合する。絶対／相対・末尾スラッシュなしの指定、`pwd`、ブラウザーの親子リンク、存在しないパスとファイルのディレクトリ扱い拒否、既存map/opsの一覧保持を確認する。時計・選択対象・カメラ・セーブの保持と元環境への復帰は別に記録する。建築・編集・ゲーム進行はこの読取受入に不要。

この2パスの限定受入は、全仮想パスや保存ディレクトリの正当性、全詳細ファイル、全編集操作の受入ではない。親No.31とその他の残件は開いたまま保持する。

## 限定検証

既存OperationResultsホスト試験は開発側259条件、公開側253条件を含めて全体が成功。各版の修正前Listing全文と、一方の追加だけを欠いた各全文も0警告・0エラーでコンパイルでき、対象ディレクトリの実際のcd／lsで失敗した。文字列検索だけの負対照ではない。既存の英語・日本語・簡体字中国語のfood_freshnessランタイム参照と、既定の言語選択・fallbackも保持した。

開発版build.157、公開版build.74は、それぞれ自身の本体参照ビルド0警告・0エラーと、固有の識別子／設定先での停止実機281条件を確認した。親一覧→2ディレクトリ→現物IDを持つ子ファイル、明示IDによるstatus／work、相対・絶対・末尾スラッシュなしの指定、失敗時cwd保持、ブラウザーのJSON／HTML・親子リンク・設備子ファイル本文を照合した。掲載済み設備の名前／ID集合、選択した現物、停止時計、視点と保存先を読取前後で保持した。鮮度は腐敗しない既存現物のnot_applicableと理由を保持し、腐敗速度や時間進行の新しい受入へ一般化しない。

ブラウザーでobjects/details.oniをselectorなしで開いたときの必須ID／queryエラーは、ディレクトリ認識とは別の既存契約として確認した。ファイル読取へのselector引渡しや一覧の走査上限は今回変更しない。ロードに伴う元のモードへの復元は準備として分け、読取受入中の進行・施工は要求していない。

各版の切替を通常終了・Steam起動・一度の正確なロードで行い、検証後は元の導入物・設定・MOD状態・保護セーブ・停止点／視点／モード・既存画像へ復帰した。既知のnative session／Steam bookkeepingと、同内容を保った既知ファイルのmtimeだけを個別証拠付きで保持し、未知の変更を一括巻戻ししていない。公開版の結果を開発版から代用していない。個別保存先・実ID・座標・生応答・導入物のハッシュは公開文書に含めない。
