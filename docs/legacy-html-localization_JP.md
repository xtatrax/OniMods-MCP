# 旧HTML地図のページ文脈のローカライズ

対象は `/active/map/viewport.html`、同じ内容の `index.html`、および既存の `layers/layer_*.html` です。視野とレイヤーそれぞれの表題・戻るリンクの表示文・説明文、計6キーをMCPの独立した文言言語へ移しました。パス、レイヤー名、座標、幅、ゲーム側の名前と記号は変更しません。

## 原本と実行時の対応

`Localization/po/onimcp.pot`、`en-us.po`、`ja-jp.po`、`zh-hant.po` を原本とし、現在の実行時は `Catalogs/map_html.en.json`、`.ja.json`、`.zh-Hans.json` を読みます。`map_html.viewport_*` と `map_html.layer_*` の6キーを同時に維持します。自動PO読込は追加していません。既存の `map_html.unreadable` を含め、キー・placeholder・PO対応を `scripts/verify_legacy_html_localization.py` で検査できます。

暫定の `zh-hant.po` と既存の簡体字runtimeを同一視せず、後者の訳はPO注記 `Runtime zh-Hans msgstr` に別記します。ゲームの言語やStrings表を変更しません。これらはMCPの仮想ページ用の合成文脈であり、意味の一致を確認していない本体の短いUI文字列へ置き換えていません。

表題の埋込値も含め、解決・整形後の文脈をHTMLエスケープします。翻訳にHTML骨格やセル列を持たせず、読取要求の範囲や可視性を翻訳結果から決めません。

## 保持する範囲と未移行部分

セルの読取・非可視境界、色・凡例・HTML骨格・接続先は変更しません。当初の6キー移行では、表題に埋め込む既存のビュー名、通常ビュー以外の凡例、可視セルのツールチップ、エラーに従来文言を残しました。後述のツールチップ4ラベルの追加移行でも、ゲーム由来の名前や値の形式は保持します。MCPの文言言語を英語へ変えても、ページ全体やゲーム由来の名前が英語になるという契約ではありません。

既存説明の「黄色のセルは設備」は旧色表示の説明であり、各オーバーレイの全色判定を新たに保証するものではありません。今回の移行で温度・呼吸可能性・流量等の判定や描画UIとの全面一致を受入れたとは扱いません。

## 検証の境界

実Readerを接続するホスト回帰では、3言語・3経路の文脈、埋込値のエスケープ、同じセル・凡例と非可視セル保護を確認します。変更前Reader全体への差替えで新しい文脈の違いを検出し、既存の非可視境界回帰の成功とは分けます。PO／JSON対応の検査、本体DLLを参照するコンパイル、各版自身のDLLによる実機応答はそれぞれ別の証拠です。

開発側自身と公開側自身のDLLで、通常設定ページからMCP文言だけを英語・日本語・簡体字へ切り替え、各版の停止状態の9ページをそれぞれ207条件で照合しました。新規文脈と既存の座標案内・非可視案内以外のHTMLは言語間で一致し、6時計とAPI精度でのカメラ、全設定の復帰を確認しました。各版のホストで新規82条件と従来の地図回帰・旧Reader差替え負試験、本体参照ビルドを別々に確認しています。公開版は専用の設定とパッチ所有者も実機で確認しました。

保存やシミュレーション進行を要求せず、各版の通常終了後に元の導入物・設定・既存画像と未起動状態へ戻しました。HTML応答の確認は、ブラウザーの実ピクセル、全DLC・全オーバーレイ・任意の他MOD構成、非日本語ゲームでのauto追従の受入を意味しません。

ボタンを生成するHTMLシェル全文と実際のローカライズ読込・カタログを接続したホスト回帰で、3言語のラベル、属性のエスケープ、周囲のHTMLの保持を確認しました。引用符・HTML／script境界等を含む文言は合成fixtureだけで照合し、製品カタログには含めていません。変更前のHTML全文では、新しいラベル条件が意味的に失敗する負対照も確認しました。従来Readerの回帰とPO／runtime対応の検査、本体DLLを参照するコンパイルは別々の証拠です。

開発版・公開版それぞれ自身のDLLと設定で、通常設定ページからMCP文言だけを3言語へ切り替え、視野・index・高さ別layerのHTMLを確認しました。代表ページではブラウザーでRaw表示への切替と地図への復帰を操作し、両ラベルと表示状態を照合しました。ゲームの言語を変えず、停止時計の6項目・報告カメラとLanguage以外の設定を保持し、元の言語設定へ戻した後も別の読取で確認しました。公開版の設定先と所有パッチIDは公開版自身で照合しました。

保存・時間進行を要求せず、通常終了後に元の導入物・設定・保護セーブ・既存画像と未起動状態へ復帰しました。この追加は2文言と既存切替の限定確認であり、未移行の凡例・ビュー名等、地図全体の実ピクセル、全DLC・全overlay・任意の他MOD構成、非日本語ゲームのauto追従までを完了したものではありません。

代表の視野ページでは各版のブラウザーで10文言・表示色・順序と警告／エラーなしも確認しました。高さ別の確認ページは全セルが未知であり、既知のゲーム内容を読んだ証拠とは区別します。各版自身のDLLによる停止実機でMCP3言語の各HTML経路と新凡例を照合し、6時計・報告カメラ・他の設定を保ち、元のMCP言語へ戻した後の読取でも全JSON値を確認しました。公開版の設定先と所有パッチIDは自身の応答で独立照合しました。保存・時間進行・ゲーム言語の変更を要求せず、通常終了後に元の導入物・設定・保護セーブ・既存画像と未起動状態へ復帰しました。

## 可視セルのツールチップ4ラベル

視野／indexと高さ別layerの2生成分岐で、可視セルの `Cell`、`Element`、`Temp`、`Building` だけをMCP独立言語へ移した。`map_html.tooltip.{cell,element,temperature,building}` をPOの `OniMcp.MCP.MAP_HTML.TOOLTIP.*` へ対応付け、POTと3言語PO、既存runtime JSON3を同時に維持する。既存の凡例 `map_html.legend.building` とは表示文脈を分け、別の実行時aliasやPO読込経路は追加しない。暫定Hant原本と既存Hans runtimeは従来どおり注記で区別する。

4ラベルは各ページのセルloop前に一度だけ解決する。英語の従来出力、コロン・空白・改行・単位、セルID／座標、元素IDと設備のnative名は保持する。温度は従来の `F1` 補間を残し、数値書式には現在のCultureが引き続き適用される。MCP文言の言語指定から数値の小数点やゲーム言語を切り替えない。ラベルと既存値を組み立てたツールチップ全体を、従来の最終挿入先でHTMLエスケープする。

ゲームの値取得、色、既知／未知の境界、HTML骨格とRaw切替は変更しない。既存の未知セルメッセージとnative値を読まないガードを保持し、翻訳のためにゲームのキャッシュ準備、画面更新、状態の再評価を呼ばない。真空の温度値や欠測の意味を、この文言移行で修正・再判定したものではない。管理画面の入力フォーカスや表示操作も対象外である。

実Readerと実カタログを接続した新673条件は、3言語・2Culture・3経路、完成設備名／非完成物の名前／設備なし／既知セルの元素参照なしを照合した。native名にタグ・引用符・ラベルに似た語句がある場合のエスケープと値の保持、既知セルの反復、未知セルがnative値を取得しない境界も対象とする。既存の言語間比較は4ラベルの先頭部分だけを正規化し、それ以外の値やマークアップを一致させる。旧Reader全文の負対照はコンパイル成功後、新しい日本語ツールチップの意味条件で失敗した。PO／JSON対応、本体参照ビルド、既存HTMLシェルの69条件と注入境界23条件も別に確認した。後二者はRaw切替等の既存境界であり、任意の翻訳文をこの4ラベルへ新たに注入した試験ではない。

両版それぞれ自身のDLLで、MCP3言語の視野・index・高さ別layerの各9ページと同じ9ページの再読を、停止状態で確認した。ラベル、セルの残りのHTML・値・色・既知／未知の区別と反復結果を照合し、6時計項目と報告カメラを保持した。日本語の代表ページでは、DOMの `title` 属性、Raw表示から地図への往復、ブラウザーエラーなしと代表描画を確認した。DOMの属性値の確認を、ブラウザー標準のhoverツールチップが出現することや、その全ピクセルの確認へ代用しない。
