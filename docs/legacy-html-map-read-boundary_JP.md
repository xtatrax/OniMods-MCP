# legacy HTML地図の読取境界

`/active/map/viewport.html`、`/active/map/index.html` と `/active/map/layers/layer_*.html` は、既存のテキスト地図と同じ「現在のワールドで可視のセル」という読取範囲を使います。ワールドにはロケット内部なども含まれるため、天体だけを指す契約ではありません。

セルが無効、ワールド内の有効セルではない、非可視、現在のワールドとは異なる、または有効な現在ワールドIDを取得できない場合は、`data-state="unknown"`、固定の不明色、MCPの表示言語に対応する不明ツールチップを返します。その分岐では、元素・温度・設備・オーバーレイ色を取得しません。空セルや真空、正常な温度として扱う表示へ置き換えません。

読取範囲内のセルは、既存の元素名・温度表示・設備名・色への引数・凡例・ページ案内を維持します。動的なツールチップはHTMLエンコードします。可視セルで元素が取得できない場合の既存表示、HTMLへの範囲指定やセル数予算の扱いなど、この境界修正とは別の契約は変更しません。

## 他の地図経路との関係

- 仮想Markdownのviewport、layer、zoom等は、既存の可視セル・現在ワールドの読取方針を維持します。この変更でMarkdownの引数や出力形式は変更しません。
- 人間向け `/active/map/current-world-map/` とその `data.json` は別の表示契約です。現在のワールド全体を取得し、未探索領域を隠す表示を切り替えられる既存の動作を維持します。今回のlegacy HTML境界を、人間向け全体表示へ一律適用する変更は行いません。

## ローカライズ

独自tooltipは `map_html.unreadable`、PO contextは `OniMcp.MCP.MAP_HTML.UNREADABLE` を使います。PO4とruntime JSON3を揃え、英語・日本語・従来のzh-Hansを別々に解決します。暫定 `zh-hant.po` の訳をruntime zh-Hansへ転用しません。

## 検証の範囲

開発版・公開版それぞれで、実際のlegacy HTML reader全体と既存の読取方針をリンクするホスト試験435項目と各版の既存地図試験を通しました。非可視・別ワールド・無効セル等で、元素・温度・設備の参照と色取得を禁止する境界を使います。可視セルの温度、HTMLエンコード、表示言語、オーバーレイへの引数も確認しました。開発側では旧reader全文を同じ試験へ差し替え、コンパイル成功後に非可視セルの意味的な検査で失敗する負対照を確認しました。

開発版・公開版それぞれ自身の本体参照ビルドと停止実機で、既存HTMLのviewport・index・高さ別layerを読みました。開発側で、同一の未探索セル1点についてMarkdownの `?` と既存可視性読取の `hidden` に反し、旧HTMLに元素・温度が含まれる不一致を再現しました。修正後は両版とも同じ保存状態の同一セルを不明表示にし、可視範囲のセル属性・温度・設備名・色とページ外枠・凡例を保ちました。公開版自身のID・設定先・所有パッチも照合しました。

公開版には開発側の可視性スナップショット窓口を追加していません。公開側の直接確認はMarkdownの `?` とHTMLの不明表示の対応であり、開発側で別途得た `hidden` 理由を公開側の直接計測とは扱いません。両版で元セーブ・停止時計・報告されたカメラを保持し、通常終了後に元の導入物・設定・他MOD・既存画像と開始時の未起動状態へ復帰しました。

ホストの描画外枠と色計算は境界モデルです。別ワールド・無効セル・現在ワールド欠測・各オーバーレイ・三言語はホストで確認した範囲と区別します。未探索の直接実機証拠は現ワールドのlayer内1点で、viewport/index内の未探索、ワールド切替や読込中の全状態、ブラウザーの実ピクセルまで検証したものではありません。人間用current-world-mapの表示契約も別です。個別の生応答・対象座標・保存先は一般文書へ含めません。
