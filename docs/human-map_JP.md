# ブラウザー向け現在天体マップ

`http://localhost:8788/active/map/` は従来のファイル一覧を表示し、既存と同じ表形式で `current-world-map/` の行を追加した。リンク先の `http://localhost:8788/active/map/current-world-map/` で、現在の天体全体を表示する。ブラウザー向けアドレスを変更している場合は同じパスを使う。

- ドラッグで移動、ホイールまたは＋／−で拡大縮小。「全体」で天体全域、「拠点」で複製人間の周辺へ移動する。
- 元素・温度・酸素・質量・電力／液体配管／気体配管／自動化／輸送を切り替える。
- 設備の輪郭はネイティブの実占有範囲。拡大すると名前と端子を重ねる。複製人間はミント色の点。
- セルをクリックすると座標・元素・温度・質量・設備・端子を表示。「詳細を開く」で既存セル詳細へ進む。
- 未探索セルは既定で隠す。チェックを外すと全領域を表示する。温度や質量の表示色は観察用の目安であり、設備や複製人間の安全診断ではない。
- 初回は一度取得するだけ。「更新」、または任意の「5秒ごとに更新」で取り直す。非表示タブでは定期更新を止める。失敗時は取得失敗を表示し、再試行できる。
- Y+は上（地表方向）、Y−は下（地下方向）。表示行を上下反転して、ゲームの上下と一致させる。
- キーボードではキャンバスへフォーカスして矢印キーで移動、＋／−でズーム、0で全体表示。

ブラウザーの移動・ズーム・表示変更はブラウザー内だけで行い、ゲームのカメラ・オーバーレイ・時間・建設状態は変更しない。現在の天体を対象とし、別天体へゲーム側で移動した後に更新すると新しい天体を表示する。世界座標を用い、他天体の領域は混ぜない。

元のHTMLファイル一覧は `/active/map/`、JSON一覧は `/active/map/?format=json` に残し、既存の `index.html`、`viewport.md`、高さ別レイヤーとMCP向け契約を保持する。新しいブラウザー用JSONは `/active/map/current-world-map/data.json`。静的HTML/CSS/JSはMOD DLLに埋込み、外部CDNには依存しない。
