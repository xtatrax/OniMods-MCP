# セルのPickupable集計と分類キー

既存cell_infoの `pickupableSummary.groups` は、表示名・native prefab identity・元素を構造化したキーで分類します。同じ名前でも別prefabや別元素なら分け、一群へ最初の種別ラベルを貼ったまま全量を足しません。新しい公開tool・返却field・移動/掃除操作は追加しません。

## 分類と未取得

- 既存のcleaned name、KPrefabIDの有効なPrefabTag.Name、PrimaryElement.ElementIDを使います。表示名から種別を推測せず、IDや名前を区切り文字で連結しません。文字列比較はordinalで、異なるfield境界を混同しません。
- name・prefab identity・元素の取得根拠が揃う現物は、三つの値が一致する場合だけ同じgroupへ数えます。同じprefabでも表示名や元素が違えば別groupです。stored/looseはgroup内の従来の内訳です。
- 名前の欠測は既存fallbackを使う前に区別します。表示名が実際に文字列Unknownであることと、欠測をUnknown表示にしたことを混同しません。名前かprefab identityが欠測、またはPrimaryElementが無い場合は、そのGameObjectの参照identityを内部keyに加え、根拠なく別個体とまとめません。
- KPrefabIDオブジェクト自体のEqualsはPrefabTagの同値性であり、個体比較には使いません。未知個体の参照identityはその読取呼出内だけのものです。新たな個体IDを生成して返したり、保存/再読込をまたいで同じ参照になると主張したりしません。
- ElementIDがnative enumの未定義数値でも、既存fieldのraw値として文字列化します。新しいenum適否判定やElement registryの照会で欠測へ変えません。lazyなPrimaryElement.Element getterは追加で呼びません。

未知個体が同じ表示fieldを持っていても別group行になり得ます。同じGameObjectの重複観測は、従来どおり観測entryとして加算し、registry重複のdedupや個体一覧の書換えは行いません。groupが分かれたことだけを、新たな物体の生成や質量増加と解釈しません。

## 順序・上限と既存値

従来のmassKg降順・nameのordinal順を保ち、その後をprefab identity・元素のordinal順、最後に最初の観測順で決めます。未知個体の完全なtieは同じregistry入力内のencounter順です。独立した再読込でunknown同士の順序まで固定する契約ではありません。

最大16groupを返す既存上限を保ち、truncatedは分割後のgroup数から計算します。全体のcount・stored・loose・totalMassKgと各groupの丸めは従来のままで、個別pickupablesの読取やIDも変更しません。新規group fieldや重い現物詳細を既定返却へ追加しません。

summaryの対象セルは従来通りcachedCellまたはGrid.PosToCellで判断し、world選別を維持します。個別pickupablesや他の窓口の選別を一括で変更したものではありません。既存のPrimaryElement欠測/非有限massの補正、収納/装備や生存/死亡/卵の分類、掃除の実行除外、食品集計は今回のgroup key修正とは別です。欠測massが旧経路で0になる意味まで解消したとは扱いません。

## 本体との境界と検証範囲

追加keyは既存PrefabTag.NameとElementID等のcache値を使い、腐敗状態や表示名の規則を再評価しません。元のGetProperNameは従来と同じ読取を維持します。新しい生成・移動・改名・腐敗進行・native refreshは呼びませんが、旧getterのログ等を含む読取全体で副作用が皆無という保証へ広げません。

核心となる同名/異prefab・異element、名前欠測と実名Unknown、未知の別個体、delimiterを含むfield、上限/順序は実sourceを連結したホストで確認する必要があります。native入力の代替と、ゲーム内の同名混合の観測は別の証拠です。

両版の初回と通常再読込を停止中に照合し、現存する同種の集約・複数種の分離、全体と個別の件数・収納内訳・質量、反復と停止時計を確認しました。既存Markdownはgroupと個別詳細をそれぞれ既定8件まで表示するため、その部分表示を全現物の証明として扱いません。元導入物・対象設定・原本・共有保存・保存先選択・他MOD/DLCと元版の未ロード入口へ復帰しました。同じ接続sessionや全preferencesのbyte一致を主張するものではありません。

同名/異prefab・異element、名前欠測と実名Unknown、未知の別個体、delimiterを含むfield、16group上限とtie順序の核心は、実sourceを連結したホスト境界で確認したものです。過去に観測した同名異種pairは現在の入力では再現せず、有限の検索で候補が無かったことを全体の不存在とは解釈しません。今回の実機受入で同名混合現物の修正を直接再現したとは扱いません。

旧GetProperNameはblank名でログとfallbackへ到達し得る経路を維持し、PrimaryElement欠測/非有限massを旧経路で0へ補う意味も今回変更していません。分類キーの修正を、全getterの無副作用や欠測質量の解消へ広げません。親項目の生物分類・収納/装備・掃除全体、同名混合現物と通常UIの照合は残ります。
