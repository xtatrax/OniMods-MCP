# 標準液体ブリッジと完成済み前景設備の重なり

標準の `LiquidConduitBridge` は接続端点のレイヤーを使用するため、完成した通常の前景設備と同じセルを通れる場合があります。予行で前景の物理範囲を一律に障害物とすると、本体の通常カーソルが許可する位置を拒否していました。

この修正は、既存のネイティブ定義から標準の3セル液体ブリッジと確認できる場合だけ、完成済み前景設備との重なりを予行の障害物から外します。相手の定義・完成状態・ワールド・占有形状も取得でき、対象セルのBuildingレイヤーに同じ個体があることを必要とします。ネイティブの配置可否を再評価したり、素材や接続を書き換えたりしません。

次の検査は維持します。

- ネイティブ接続端点の正確な対象レイヤーと既存占有。
- 座標・可視範囲・ワールド・既知の形状、地形と植生。
- 設計図、タイル、別ブリッジ、不明な設備や変更された定義。
- 他の種類のブリッジに対する従来の保守的な判定。

端点が衝突する位置は、前景の重なりを除外しても拒否します。予行の許可を、素材の運搬可能性・通常工事の完成・通水の保証へ読み替えないでください。施工は既存の通常経路と安全条件に従います。

検証では、同じ定義・素材・向きのまま、端点衝突と、端点を避けて完成設備だけを跨ぐ対照を分けます。開発側の本体カーソルの色観測と、各版自身の通常予行は別の証拠として扱います。カーソルから取得できない拒否理由は未取得のまま保持します。

ロード直後など本体の素材選択が準備段階に留まる場合は、カーソルを取得できたことにしません。読取のためのキャッシュ強制生成や自動的な時間進行は追加しません。
