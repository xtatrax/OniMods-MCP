# 操作ファイルの捕獲例の表示範囲

通常の操作ファイルに表示する既存3本の捕獲例を、`/active/ops/orders.md` と `/active/ops/ranching.md` だけへ揃える。従来は条件分岐の波括弧がなく、最後の2本が他の21ページにも混入していた。条件を囲む2つの波括弧を加え、対象3行のインデントだけを整える。`ops/tools.md` は別の一覧Readerを使うため、通常23ページの検査には含めない。

例のDSL文字列、実行parser・capability・安全確認・本体への操作経路、ローカライズキーは変更しない。各ページの案内を読んだだけでは例を実行しない。捕獲例は対象2ページに各1回ずつ、従来の順序でコメント行として残し、それ以外のページでは既存の通常例を残す。

開発版と公開版それぞれ自身の既存OperationResultsホスト回帰が成功し、操作コマンド上限の契約検査は309件を含む。実際の登録表から通常23ページを取得する追加検査で、捕獲例の有無・対象ページの末尾順序・見出しとコードフェンス・コメント形式・子操作の呼出しなしを確認した。修正前のReader全文へ差し替えた負対照はコンパイル後に実行へ到達し、`ops/any.md` への捕獲例混入を意味検査で検出した。既存のローカライズ・コマンド制限等のガードは保持する。

開発版と公開版それぞれ自身の本体参照0警告0エラーと配備DLLの停止実機で、通常23ページと対象・非対象6ページの反復を取得した。捕獲3例は対象2ページに各1回、他21ページには0回で、対象の末尾順・コメント枠と反復全文が一致した。元セーブ・6時計・報告視点・固有設定先と所有パッチ／重複なしを保持し、保存・進行・例の実行を要求せず通常終了した。元導入物・設定・画像・保護セーブ・他MOD／DLC・共有データと未起動状態へ復帰した。公開版固有の設定先・所有パッチIDと重複なしも独立に照合した。切替時の単一MOD不一致は、観測した対象を通常OKへ一度だけ委譲して停止を保持した。

実機の根拠は生成本文と読取要求・状態の一致であり、内部のnative子実行を独立計測したものではない。その他の例がすべて現行契約へ適合しているという意味でもない。

受入対象は案内に出る例の表示範囲に限る。捕獲コマンドの実行、捕獲の成立、牧畜作業の完了、その他すべての設備・作業案内を確認した意味ではない。操作案内全体の整理は引き続き残る。
