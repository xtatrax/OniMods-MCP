# このプロジェクトに関心を寄せる皆さんへ

このプロジェクトに関心を寄せる皆さんへ。

最近、少し変わったことに取り組んでいます。

OniMods というプロジェクトです。

その中の1つが、AI が *Oxygen Not Included* の世界に入れるようにする MCP MOD です。

単に AI に質問へ答えてもらいたいわけではありません。

もう一歩踏み込んで、こんなことを探ってみたかったのです。

AI は、ルールのある世界を理解し、周囲の環境を観察し、判断を下し、単なる道具ではなく、その世界の参加者になれるのでしょうか。

その好奇心が、このプロジェクトの始まりでした。

けれど、開発を進めるうちに、すぐに問題に気づきました。

かなりお金がかかるのです。

AI が判断を下すたびに、トークンを消費します。

ゲームのように動き続ける環境では、費用も急速に膨らんでいきます。

私は一人の大学生です。

背後に会社や投資家、開発チームがいるわけではありません。

費用の大半は、自分で負担してきました。

このアイデアを形にするために、コードを書き、モデルをテストし、問題を調べて直すことに数え切れないほどの時間を費やし、大量のトークンも使ってきました。

ときどき、自分に問いかけます。

個人のプロジェクトに、ここまで力を注ぐ価値があるのだろうか。

それでも、AI がゲームの世界を理解し始める姿を見るたびに、誰かがこの実験に興味を持ってくれるたびに、続ける価値があると感じます。

ただ寄付をお願いするだけにはしたくありません。

プロジェクトを支援してくれる人も、何か価値のあるものを受け取れる仕組みを作りたいと思っています。

そこで、次のサービスを作りました。

[https://api.lmm.best](https://api.lmm.best)

AI API のサービスプラットフォームです。

ここでトークンを購入して AI サービスを利用すると、同時に OniMods の継続的な開発費を支えることにもつながります。

収益の一部はオープンソース開発の支援に充てます。[ソースコード](https://github.com/TokenNotIncluded/api.lmm.best)は現在、[TokenNotIncluded](https://github.com/TokenNotIncluded) の組織で公開しています。

貢献してくれる方にも、お返しをしたいと考えています。

たとえば、次のような形で参加していただけたらうれしいです。

* Issue を提出し、問題の発見を手伝う。
* プルリクエストを提出し、コードを改善する。
* アイデアや提案を共有する。
* 新機能のテストを手伝う。

可能な範囲で、トークンによるお礼を提供していきます。

小さな循環を作れたらと思っています。

サービスを使う人が、プロジェクトの継続を支える。

オープンソースに貢献する人が、プロジェクトをより良くする。

そして私は、さらに面白いアイデアを形にするために、時間を注ぎ続ける。

OniMods は、今はまだ小さなプロジェクトです。

けれど、意味のある取り組みの多くは、素朴な思いつきから始まります。

「これが本当にできたら、どうなるだろう？」

そして誰かが、時間をかけてそれを形にしていきます。

このプロジェクトに注目し、使い、貢献し、支えてくれるすべての方に感謝します。

この好奇心を、長く持ち続けられたらと思っています。
