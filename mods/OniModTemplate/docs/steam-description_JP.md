[h1]OniModTemplate[/h1]

[b]Oxygen Not Included の MOD テンプレートプロジェクト[/b]

[h2]用途[/h2]
[list]
[*] ONI MOD をすばやく作成するための、最小構成のテンプレートです。
[*] ゲームへのパッチを書き始める前に、基本的なひな形を必要とするチーム向けです。
[*] `onim` を使ったビルド・公開の手順に対応しています。
[/list]

[h2]特長[/h2]
[list]
[*] 短いサイクルで開発を進めやすい、定義済みのプロジェクト構成。
[*] 基本的な `ModInfo` エントリーポイントを収録。
[*] 学習、テスト、開発環境の立ち上げに利用できます。
[/list]

[h2]対象となる方[/h2]
[list]
[*] 新しい ONI プロジェクトを一から作る MOD 開発者。
[*] パッチや実験用に、一貫したひな形を必要とする方。
[*] 見通しのよい共通の初期構成を求めるチーム。
[/list]
