[h1]CycleTrim[/h1]

[b]Oxygen Not Included 向けの軽量なパフォーマンス改善 MOD[/b]

[h2]v0.3.1 の修正[/h2]
以前の CycleTrim は、`currentChore` が null でなければ作業中と判断していました。ONI は複製人間の待機中も null ではない `IdleChore` を保持するため、待機中の複製人間の拾得候補と作業の更新にも頻度制限がかかっていました。

v0.3.1 では `IdleChore` を除外しました。待機中の複製人間は原版の即時更新を使い、実際に作業中の複製人間には頻度制限を維持します。

現在の ONI ビルドや他の MOD が `Manager.TickFrame()` を書き換えている場合は、例外を投げて MOD 全体を無効化するのではなく、非同期の経路探索の処理枠を最適化するパッチだけをスキップします。

[h2]この MOD が変更するもの[/h2]
CycleTrim は、頻繁に実行される6つのシミュレーション処理から重複した処理を取り除きます。複製人間の優先度、スケジュール、経路の規則、作業の条件は変更しません。

[h2]主な最適化[/h2]
[list]
[*] 液体貯蔵庫・気体貯蔵庫: 重複した自動化信号の送信を減らします。
[*] 拾得候補の検索: 候補のコスト計算と順位付けの準備処理をキャッシュします。
[*] 作業中の複製人間: 負荷の高い更新の頻度を制限します。`IdleChore` は明示的に制限対象から外し、待機中の複製人間は原版の応答性を維持します。
[*] 静止している動物: `Navigator` の重複した探索と、経路探索の高負荷処理を減らします。
[*] 通常の Creature の Brain スケジューリング: 高描画フレームレート時に、原版の Creature の通常処理の頻度を制限します。Dupe、カスタムの Brain グループ、優先処理は原版どおりです。
[*] AsyncPathProber: 正常に適用された原版 Creature のスナップショットだけを重複排除し、ワーカー数・処理中の件数に応じて処理量を制御します。Minion、Robot、カスタムの abilities は原版どおりです。
[/list]

[h2]互換性[/h2]
ゲーム本体と DLC に対応しています。複製人間、ロボット、カスタムの Brain グループ、優先処理は、パッチが適用できない場合に原版のコードを使います。

[h2]性能[/h2]
条件を固定した場面での測定結果であり、すべての環境に当てはまるものではありません。
[list]
[*] 作業中の複製人間の頻度制限: FPS 中央値 70.6 → 85.1（+20.6%）、Brain 合計処理時間 5.087 s → 2.449 s（-51.9%）。
[*] 静止した動物の頻度制限: FPS 中央値 81.23 → 109.28（+34.5%）、Navigator の高負荷処理の合計時間 826.852 ms → 47.970 ms（-94.2%）。
[*] UpdatePickups キャッシュ: 平均処理時間 41.279 µs → 35.708 µs（-13.5%）。
[*] 通常の Creature の Brain 合成ベンチマーク: スケジュールされた呼び出し回数 43,200 → 19,200（-55.56%）。
[/list]

[b]注意: Brain の数値は、240 FPS × 30秒の独立した関数単位の合成ベンチマークによるもので、ゲーム内の FPS テストではありません。[/b]
Creature の呼び出し回数は 36,000 → 12,000（-66.67%）、ローカルの経過時間の中央値は 255.580 ms → 113.289 ms（-55.67%、2.26x）でした。実際の改善幅は、コロニーと実際の Brain の処理負荷によって変わります。

[b]PathProbe のマトリクスも合成ベンチマークであり、FPS ではありません。[/b] 目標ヒット率 0/25/50/75/90% に対し、10,000リクエストで実行された探索は 10000/7701/5501/3301/2000 回で、理論上の処理削減率は 0/22.99/44.99/66.99/80.00% でした。8回連続してスキップした後は、強制的に更新します。
