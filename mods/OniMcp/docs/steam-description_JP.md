[h2]この MOD でできること[/h2]
[list]
[*] コロニーの状態確認と安全な操作のために、ローカルの MCP 対応サービスを起動します。
[*] `oni://` リソースと、まとめられたツールの入り口（`world_editor`、`game_control`、`building_control` など）を公開します。
[*] 範囲を限定した監査可能な結果を返し、リスクのある変更には確認を要求します。
[/list]

[h2]主な用途[/h2]
[list]
[*] コロニーのスナップショット取得と周辺環境の確認。
[*] 小規模で安全な自動化（一時停止、速度変更、スクリーンショット、小さな建築や保守作業）。
[*] 構造化されたゲーム操作手順のための MCP クライアント連携。
[/list]

[h2]安全性と対象範囲[/h2]
[list]
[*] 長時間の自律操作では、実行時間を区切り、一時停止して検証するループと、リスクの確認を使ってください。
[*] 高リスクな操作には、明示的な確認が必要です。
[*] ローカルのループバック以外に公開する場合は、ネットワークの公開範囲と認証を適切に設定することを推奨します。
[/list]

[h2]任意のプロジェクト支援[/h2]
[url=https://api.lmm.best]AI トークンの購入（任意）[/url]で、OniMods の開発を支援できます。この購入は、MOD のローカル認証トークンとは無関係です。OniMcp の利用に、このサイトへのアクセスや購入は必要ありません。対応する MCP クライアントとモデルは自由に選べます。

[h2]ベンチマークスキル[/h2]
[list]
[*] エージェントで `benchmark` ツールを使い、固定の呼び出し経路の性能を検証できます。
[*] 出力は、標準化された JSON オブジェクト（`status`,`ok`,`suite`,`suiteStartedAt`,`suiteEndedAt`,`durationMs`,`summary`,`results`）です。
[*] 各結果の主なキーは `name`,`status`,`iterations`,`durationMs` で、項目固有の指標と、必要に応じて `error` を含みます。
[/list]
