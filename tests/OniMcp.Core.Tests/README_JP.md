# OniMcp コア機能の回帰テスト

.NET 10 SDK で実行する。ONI のインストールは不要。

```sh
dotnet run --project tests/OniMcp.Core.Tests/OniMcp.Core.Tests.csproj -c Release
```

この実行ファイルは、本番用の MCP 型、レジストリ、リソースのルーティング、ミドルウェアをリンクして使用する。JSON-RPC の null フィールド、初期化の再試行、不正なツール引数、公開範囲とメタデータのキャッシュ分離、登録済みのすべての静的リソース、リソーステンプレートのクエリによる上書きを確認する。いずれかのグループが失敗すると、終了コード 1 で終了する。

navigationのファクトリと英語説明の上書きは実際の製品ソースをリンクする。nativeカメラ実行は例外で拒否する。既存のresourceルーティング群だけは記録用ハンドラーへ一時差替えし、必ず元へ戻す。その他のゲーム用ファクトリは記録用fixture、Unityの吹き出し表示はカウンターに置き換えている。これらのテストで検証するのは、呼び出しの振り分けとプロトコルの動作。ゲームのアセンブリとの互換性、実際のゲーム状態の読み取り、Unity の描画を検証するには、引き続き MOD 全体のビルドとゲーム内のスモークテストが必要になる。

追加metadata群は既存navigationのactionとfield集合を保持し、日本語で生成したmetadataを実Registry／Localizer経由で英語・日本語・簡体字・autoへ切り替える。共有8正規キーのschemaは純metadata fixtureであり、owner factoryの実行を示すものではない。実owner metadataは限定source verifierと各配備物自身のtools/listで別に照合する。gameのquery／limit上書きは実CoreEnglishソースを純metadata fixtureへ適用して検査する。

NuGetAuditを有効に保ち、出力を隔離する。NavigationControlSourceとCoreEnglishDescriptionsSourceで製品全文を差し替えた負対照を実行できる。旧英語上書きはコンパイルに成功してからquery／limitの意味条件で失敗することを確認する。ゲームDLLの実行やゲーム画面の受入へ一般化しない。
